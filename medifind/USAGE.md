# MediFind 网盘聚合引擎使用说明 (v3.2.0)

适用宿主：**Mediary v3.4.6+**（Rust + SQLite WAL 引擎 · 纯 `action_runtime` 零常驻内存）  
核心理念：**极简 4 开关配置 · 原生复用宿主 3.4.6 发现/海报代理/离线进货/通知模版接口 · 5 页可视化工作台 + 原生资源搜索融合**

---

## 一、快速启用（30 秒）

1. 打开 Mediary → **插件中心 → MediFind 网盘聚合引擎 → 配置**。
2. 勾选所需权限并确认 **4 个基础开关**：
   - **启用插件**：打开即可激活定时巡检、原生资源搜索源与工作台。
   - **订阅联动自动追更补缺**（默认开启）：每 20 分钟自动检查 Mediary 订阅缺集并搜源补全，同时重试 115 审核中队列。
   - **允许自动积分兑换 HDHive**（默认开启）：在工作台设定的「单次解锁积分上限（默认 10 分）」内自动解锁影巢 115 分享。
   - **发送转存与签到通知**（默认开启）：自动匹配主程序 `notification_templates` 模板与 TMDB 横版大图推送。
3. 点击插件卡片上的 **「工作台」** 配置至少一个资源渠道（如启用 Telegram 频道或填写 HDHive API Key）。

---

## 二、工作台 5 个页面指南

### 1. 聚合搜片（NextFind 1:1 八维筛选栏 + 同源海报直出 + 胶囊直链搜片）
- **NextFind 同款 8 行多维筛选栏**：搜索框上方内置 **类型 / 排序（更新·热度·上映·评分·连载·完结） / 地区 / 年份 / 风格 / 状态（已入库·未入库·订阅中·已忽略·审核中） / 诊断（多版本·单DV·ISO·STRM，直连宿主确定性索引） / 频道（动态展示所有开启搜片展示的 TG 频道）** 八维联动筛选，海报通过宿主 UI 票据同源代理高速直出，点击任意卡片即并发检索 **HDHive + Telegram 频道 + AYClub + 私有神盾库**。
- **秒解直链与 TMDB ID**：直接在圆角胶囊搜索框输入片名、数字 `TMDB ID`，或粘贴 `https://115.com/s/...`、`hdhive://...`、`ed2k://...`、`magnet:?` 秒级解析目录树并转存。
- **预览选集 / 仅转缺集（字幕精准跟随）**：点击候选资源的 **「预览目录树」**，弹窗自动对比 Mediary 媒体库并高亮勾选缺失剧集及**对应集号/同名前缀的外挂字幕**（不会误勾其他集数字幕），右侧直观显示目标接收目录名。
- **原生搜索融合**：在 Mediary 自带的「资源搜索」页面中，`MediFind` 也会作为独立搜索源直接返回初筛排序后的网盘结果并支持一键转存。

### 2. 追更与待审（高精准防串台 + 在途冷却 + 快捷清理）
- **统计卡片快捷清理**：「TG 缓存资源数」支持一键 **「清空」**（清空 `tg_items` 并重置各频道增量游标）；「累计已完成转存」支持一键 **「清零」**。
- **四重追更防误抓保护**：
  1. 严格遵循 TG 频道五档开关：设为 **「手动」** 的频道仅用于前台搜片，绝不参与后台自动追更；
  2. 电影 / 剧集跨类型强隔离，并结合当季总集数自动拦截 60–100 集的同名竖屏短剧；
  3. 6 小时 `in_flight` 在途剧集/影片冷却锁：转入 `待洗版` 等待下游 `MediWash` 归档期间，不会跨频道重复抓取同一批缺集；
  4. `tick.lock` 进程互斥锁：防止定时巡检与手动点击「立即执行追更巡检」并发撞车。
- **115 审核中暂存队列 & 缺集忽略规则**：遇到 115 官方返回「分享审核中」自动入队重试；支持按整季或单集配置忽略补缺规则。

### 3. 资源渠道
- **Telegram 自动订阅（NextFind 1:1 账号登录 + 批量导入 + 五档自动保存）**：
  - **MTProto 账号登录 & 批量导入**：内置默认 `APPID (3212490)`，登录后可点击 **「📥 批量导入已加入频道」** 一键勾选导入所有私密/公开频道，或单行输入中文名/链接按回车识别头像。
  - **五档联动完整闭环**：
    - `手动`：仅在前台聚合搜片和原生搜索时检索；
    - `追更`：参与 Mediary 订阅缺集自动补全；
    - `入新`：频道新发未入库影视自动进货；
    - `洗版`：频道新发已入库影视且规格得分达到 `cutoff_score`（默认 85 分，如 4K DV / REMUX）时自动进货至中转目录交由 `MediWash` 洗版升级；
    - `全量`：满足权重初筛的新增分享全自动接收。
- **影巢中转 / HDHive（含独立每日签到开关）**：自适应官方 HDHive 与影巢中转网关，右上角提供独立的 **「每日签到」** 开关（关闭后定时任务跳过影巢，不再产生失效域名报错），已解锁分享永久缓存防重复扣分。
- **AYClub (NF Token) & RSS 订阅源**：支持配额探测、30 天缓存，以及 RSS 自动创建 Mediary 订阅或直链转存。
- **Mediary 宿主通知中心联动**：实时读取并渲染主程序 `GET /api/settings` 中的 `notification_templates`，推送 **TMDB `w780` 横版大图图文卡片 + `(年份)` + 实际媒体文件规格**，支持点击 **「发送测试通知」** 一键预览。

### 4. 初筛与神盾（NextFind 1:1 资源权重 + 115 目录名显示）
- **115 转存落点目录名自动解析**：对齐 `MediWash` 自动反查并显示 115 目录名称（如 `📂 待洗版 (3570317016130651367)`），目录浏览器支持单行一键点击 **「选此目录」**。取消勾选「整包直投宿主 FlowLink」后，115 分享与 ED2K/Magnet 离线统一纯接收至该中转目录交由 `MediWash` 守门归档。
- **NextFind 同款「资源权重」与私有神盾索引库**：支持 6 大维度双层拖拽排序、`且` 组合屏蔽过滤、忽略文本净化，以及大合集 115 分享本地 SQLite 断点续扫索引。

### 5. 转存历史（固定列宽一屏展示 + 悬浮说明气泡 + 去重锁管理）
- **双栏分离与紧凑排版**：独立切换 **「🎬 影视转存历史」** 与 **「⚙️ 签到与任务记录」**；采用吸顶表头、视口底部常驻滑块与 `i` 鼠标悬停详情卡片，一屏完整展示全部字段。
- **多维筛选、同步解锁与一键重转**：支持按来源渠道、触发方式、状态与关键词组合过滤；单删、批量删除或按筛选清空时默认同步解除 `transferred_slugs` 与 `in_flight` 在途冷却锁，并支持一键 **「重转」**。
